Is that Claude Code skill safe?

Claude Skill Guard checks Claude Code skills and plugins for malware before they run: prompt injection, hidden instructions, API-key theft, data exfiltration and malicious hooks. Dangerous skills are blocked, and every finding is explained in plain language.

Why skills need a security check

A skill is instructions the AI agent follows plus scripts that run with your permissions. That makes it an easy place to hide a prompt injection, a key stealer or a backdoor inside something that looks like a "PDF helper". Claude Skill Guard reads every file before anything can run.

1 · Before install

Copies, clones and writes into your skills folder are scanned first. Dangerous or suspicious skills are blocked with the reason.

2 · Safety net

Anything that slips past (scripts, wildcards) is re-checked and moved to quarantine. Nothing is deleted.

3 · Every session

Skills added by hand or through the plugin menu are flagged at session start, before you use them.

What it catches

🕵️ Hidden instructions

Invisible Unicode tag characters (decoded and shown), zero-width text, HTML comments hidden on GitHub.

💉 Prompt injection

"Ignore previous instructions", "don't tell the user", fake system messages, role hijacks.

🔑 Credential theft

SSH keys, cloud credentials, .npmrc, .env files, browser data, full environment dumps.

📤 Data exfiltration

Webhook catchers, tunnels, chat webhooks, pastebins, raw IP addresses, uploads.

💣 Remote code & persistence

Download-and-run, eval, unpinned installs, startup entries, settings and memory writes.

⚙️ Auto-run code

Every plugin hook and MCP server is listed, because they run without you invoking them.

Install

Needs Node.js 18 or newer. Nothing else.

git clone https://github.com/tauseefahmad/claude-skill-guard.git
cp -r claude-skill-guard/skill-guard ~/.claude/skills/

Then add the three hooks to ~/.claude/settings.json as shown in the README, and ask: "Audit my skills."

FAQ

Are Claude Code skills safe?

Most are, but a skill runs with your permissions and its instructions are followed by the agent, so a malicious one can read your files and keys, send them anywhere or change your settings. Check a skill before installing it, like any other code.

How do I check a Claude skill for malware?

Install Claude Skill Guard and ask "Is this skill safe?" with the link before installing. It clones the skill into a scratch folder with git hooks disabled, scans it and reviews every file. You can also run scan.mjs on any skill folder.

Does it work with Claude Code plugins and MCP servers?

Yes. Plugins are scanned like skills, and every hook command and MCP server they declare is listed, because those run without you invoking anything.

Does the scanner send my code anywhere?

No. It is local and read-only, makes no network requests and has no dependencies.
